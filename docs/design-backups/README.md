# Design backups — TPX Travel

Self-contained HTML mockups explored during the redesign. Open any file in a browser (fonts are
embedded; visuals are pure CSS, so they work offline). Kept for reference — we may reuse these.

| File | What it is |
|------|-----------|
| `01-fonts-and-5-colours.html` | 4 bilingual (Arabic+English) font pairings + 5 distinct colour palettes on a booking mock |
| `02-mediterranean-light-dark.html` | The chosen direction — **Changa/Cairo** + **Mediterranean** palette in light & dark, with dark-mode tokens |
| `03-five-ui-styles.html` | The booking landing in 5 UI styles (Aurora, Glassmorphism, Minimalism, Bento, Soft UI) |
| `04-five-cinematic-heroes.html` | 5 cinematic hero directions with scroll + mouse parallax (Parallax, Kinetic type, Ken-Burns, Marquee, Split reveal) |

**Chosen so far:** Changa (headings) / Cairo (body) · Mediterranean palette (teal + coral) · cinematic
parallax hero. The reusable style is codified in the `premium-frontend` skill (`~/.claude/skills/premium-frontend/`).
